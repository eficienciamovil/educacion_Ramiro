# Plan de educación complementaria — Ramiro (16 años)

Plan práctico para complementar el sistema educativo español (4º ESO / 1º Bachillerato)
con aprendizaje autónomo, proyectos reales y certificaciones externas, inspirado en el
modelo Alpha: **poco tiempo, alta intensidad académica + tardes de proyectos prácticos**.

## Los tres pilares

| # | Pilar | Tiempo semanal | Archivo |
|---|-------|----------------|---------|
| 1 | Dominio matemático/científico con IA y plataformas | 3–4 h | [01-matematicas-ciencias.md](01-matematicas-ciencias.md) |
| 2 | Proyectos y habilidades del mundo real ("Proyectos de Tarde") | 3–5 h | [02-proyectos-tarde.md](02-proyectos-tarde.md) |
| 3 | Certificaciones externas complementarias | 2–3 h | [03-certificaciones.md](03-certificaciones.md) |

Total: **8–12 h/semana** encima del instituto. Es mucho: empezad por la mitad y subid.

## Cómo usar este repositorio

1. **Primera semana:** leed juntos este README y el [horario semanal](00-horario-semanal.md). Ramiro elige
   *un* proyecto de tarde del pilar 2 (lo elige él: la motivación es lo más importante).
2. **Diagnóstico:** hacer los tests de nivel de Khan Academy (matemáticas) y un test de inglés online
   (ver pilar 3). Anotar los resultados en [seguimiento/diagnostico-inicial.md](seguimiento/diagnostico-inicial.md).
3. **Cada semana:** Ramiro rellena una ficha copiando [seguimiento/plantilla-semanal.md](seguimiento/plantilla-semanal.md).
4. **Cada domingo (15 min):** revisión padre/madre–hijo con la ficha. Preguntar, no juzgar.
5. **Cada trimestre:** revisar objetivos y cambiar de proyecto si se ha terminado o se ha agotado.

## Principios

- **Autonomía guiada:** él gestiona su tiempo; los padres revisan resultados, no minutos.
- **Dominio antes que avance:** no se pasa de tema sin ≥ 80–90 % en el ejercicio de dominio.
- **La IA explica, no resuelve:** nunca copiar soluciones; usarla como profesor socrático.
- **Producir algo visible:** cada proyecto termina con algo que se puede enseñar (código, informe, vídeo, ensayo).
- **Descanso y deporte no son negociables:** si baja el sueño o las notas del instituto, se recorta este plan.
